# Publication review checklist

## Scientific and translational positioning
[ ] AIH is described as the initial experimental model, not the platform's sole indication
[ ] Strict Th1-driven rationale is distinguished from mixed Th1/Th17 or antibody-dominant disease
[ ] NT1-1 / KLRC1 target mechanism is described as a research question, not an established ITIM / SHP-1/2 mechanism
[ ] Mouse ex vivo observations are not presented as human or in vivo efficacy
[ ] Humanized antibody development and human PBMC-derived activated Th1 studies are clearly future work
[ ] No steroid-replacement or clinical efficacy claim is made

## Experimental charts
[ ] 4,300 / 150 / 80 / 60 / 40 / 30 values are identified as relative mouse immune-cell gene-expression patent-figure approximations
[ ] 130 / 4 / 3 / 4 / 3 values are identified as patent-figure approximations and PCR / FACS summary
[ ] 218.4 → 141.9 and 100 → 51.7 are distinguished from simplified 115 / 250 / 115 chart
[ ] AIH ex vivo values 250 / 245 / 160 / 120 are shown as relative signal, not animal efficacy
[ ] Th1 5.7 / Th17 0.7 is labelled mouse-cell patent-figure approximation

## Market and treatment landscape
[ ] Market estimates are attributed to publishers and base year
[ ] Geographic scope is disclosed (e.g. AIH 7MM; PBC publisher variation)
[ ] Existing treatment markets are not represented as platform TAM
[ ] Current standard treatments and limitations are accurately described
[ ] No suggestion that investigational antibody replaces insulin, levothyroxine or gluten-free diet

## IP and security
[ ] Patent titles, numbers, claims, owners and jurisdictions verified
[ ] Freedom-to-operate review completed
[ ] No API keys, passwords, database credentials, tokens or confidential unpublished data in source
[ ] Approved public contact endpoint inserted
[ ] Deployed source and network requests inspected
[ ] HTTPS, mobile layout and accessibility checked
